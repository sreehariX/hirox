# Hirox: recording guide

**Pitch:** Hirox turns an investment thesis into researched founders and startups worth meeting, explains the evidence for and against each one, and writes an editable first email.

All records below were verified in the real Supabase database on 31 October 2026. They came from actual provider requests. Open them from **Research library**, not the separate public-source example link.

## Two-minute recording

| Time | Screen and action | What to say |
| --- | --- | --- |
| 0:00–0:10 | Discover page; show the investment thesis input. | “Hirox turns a venture scout's investment thesis into researched prospects and a reasoned introduction.” |
| 0:10–0:25 | Research library → **Seed-stage companies & builders working on reliability tooling for AI agents**. | “This run researched three supplied targets through actual API calls. The activity panel shows the work and cache hits.” |
| 0:25–0:45 | Select **Cekura**. Show Meet, case for, concerns, and one citation. | “Cekura fits the seed-stage thesis. The recommendation has inspectable evidence and counterarguments.” |
| 0:45–0:55 | Select **Composio**. Show Pass and Series A stage. | “Composio is a strong company, but Series A excludes it from this seed-only thesis.” |
| 0:55–1:05 | Select **Shreya Shankar**. Open source coverage notes. | “Multiple people share this name. Hirox flags the identity ambiguity and chooses Watch.” |
| 1:05–1:20 | Return to Cekura → Connections, then Sources. | “Crustdata connects companies, founder experience and professional activity. Firecrawl extracts web evidence. Relationships link back to sources.” |
| 1:20–1:45 | Cekura → Draft. Show saved draft and citations, edit one sentence, Save edits. | “The result is a specific, editable introduction. I can copy or export it. Hirox stops at a draft.” |
| 1:45–2:00 | Research library → **Seed-stage startups & builders of tooling for reliable AI agents**. | “This separate run discovered Amjad F., Omry Damari and Jeswin Cyriac with no supplied names. We can find relevant people before a company profile exists.” |

If the video permits a longer live section, begin a one-prospect run before recording and show its activity. Real research can take several minutes. Label any time jump; completed genuine runs are already available for an uninterrupted walkthrough.
